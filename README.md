# Codex Pet — Windows 첫 버전

`app/DesktopPet.exe`를 더블클릭하세요. 현재 PC에 설치된 .NET Desktop Runtime 10을 사용합니다.
다른 PC에서는 해당 런타임이 필요합니다. 자동 시작 등록은 하지 않습니다.

## 사용법

- 책상 앞에 앉은 3D 고양이를 클릭하면 작업 상태와 계정 사용량 패널이 열립니다.
- 다시 클릭하면 패널을 접습니다.
- 고양이를 드래그하면 위치를 바꿉니다.
- 우클릭 메뉴에서 항상 위에 표시를 끄거나 앱을 종료합니다.
- 실행 중에는 고양이 위의 점 세 개가 움직입니다. 현재 이미지는 정지 이미지이며,
  앞발 타이핑·졸기 등의 캐릭터 프레임 애니메이션은 아직 적용하지 않았습니다.
- 작업 목록에는 현재 실행 중인 작업만 표시합니다. 완료·중단·상태 불명 작업은 제외합니다.
- 실행 중인 작업이 없으면 쉬는 중 안내가 표시됩니다.
- 패널은 베이지색 `#F5E8D5`, 글씨와 사용량 포인트는 갈색 `#664A30`입니다.

## 연결 방식과 한계

`CODEX_HOME` 환경 변수가 있으면 해당 폴더를, 없으면 사용자 홈의 `.codex` 폴더를 사용합니다.
`sessions/**/*.jsonl`에서 최근 수정된 12개 세션을 읽고 `session_index.jsonl`의 이름을 연결합니다.
패널에는 그중 실행 중인 작업을 표시합니다. 3초마다 확인하며 이미 읽은 로그는 다시 처리하지 않습니다.
큰 로그에 처음 연결할 때는 마지막 4MiB부터 확인하므로 시작 이벤트가 없으면 상태를 확정하지 않습니다.

`task_started` → 작업 중, `task_complete` → 완료, `turn_aborted` → 중단으로 표시합니다.
실행 중인데 3분 이상 새 기록이 없으면 ‘상태 확인 필요’가 됩니다. 장시간 명령도 이 표시가 나타날 수 있습니다.
활동 설명은 기록의 도구 이름으로 분류한 것으로, 에이전트의 내부 사고 내용이나 정확한 진행률이 아닙니다.
승인 대기는 현재 버전에서 별도 판별하지 않습니다.

토큰은 로그에서 읽은 세션 누적값입니다. 계정 사용률은 설치된 Codex의 `app-server`를 통해
공식 `account/rateLimits/read`로 직접 조회합니다. 앱 시작과 패널 열기 시 즉시 조회하고,
이후 15초마다 갱신합니다. 서버 집계 지연이 있을 수 있으며 순간적인 푸시 동기화는 아닙니다.
조회 시각과 초기화 예정 시각을 함께 표시합니다. 실패하면 오류 안내와 함께
마지막 성공 값임을 표시하며 로그 사용률로 대체하지 않습니다.
초기화 시각이 지난 기록은 ‘갱신 대기’로 표시하며 0%라고 단정하지 않습니다.

이 연결은 Codex의 내부 로그 형식에 의존하므로 향후 업데이트에 맞춘 수정이 필요할 수 있습니다.
펫이 인증 파일을 직접 읽지는 않습니다. 설치된 Codex 클라이언트가 기존 로그인으로
계정 서버에 사용량을 요청합니다. 작업 내용은 이 조회에 전송하지 않습니다.
펫은 Codex 설정과 원본 기록을 직접 수정하지 않지만 Codex 클라이언트는 자체 실행 기록 등을 저장할 수 있습니다.

## 파일 구성

- `CodexPet.csproj`: Windows WPF 앱과 .NET 10 빌드 설정.
- `Monitor.cs`: 로그의 완성된 줄만 증분 처리하고 상태·모델·토큰·계정 사용률을 정리합니다.
- `AccountUsage.cs`: Codex App Server 연결과 계정 사용률 조회·타임아웃·연결 정리를 담당합니다.
  화면의 계정 사용량은 이 파일의 결과를 사용하며 Monitor의 과거 사용률은 표시하지 않습니다.
- `App.cs`: Monitor의 결과를 3초마다 받아 고양이 애니메이션과 클릭 패널을 갱신합니다.
  PetDrawing에 작업 상태를 전달하고 50ms 타이머로 애니메이션 프레임 갱신을 요청합니다.
- `Assets/cat-desk.png`: 두 뒷발이 보이는 최종 승인 이미지 원본입니다.
- `CodexPet.csproj`: 이미지를 앱 리소스로 포함해 실행 파일과 함께 배포되도록 합니다.
- `Tests.cs`: 시작·완료·중단·오래된 상태·잘못된 JSON·분할 기록·로그 축소 처리를 검사합니다.
- `app/`: 빌드한 실행 파일과 필요한 동반 파일입니다. 폴더 전체를 함께 보관하세요.

## 개발 및 검사

프로젝트 폴더에서:

```powershell
dotnet build -c Release -o app
Start-Process app/CodexPet.exe -ArgumentList '--self-test' -Wait
Get-Content app/test-results.txt
```

`--snapshot`은 실제 로컬 기록을 읽은 패널을 `app/preview.png`로 렌더링하고 종료합니다.
미리보기에는 작업 제목과 사용량이 포함될 수 있으니 외부 공유 전에 확인하세요.

## 타이핑 애니메이션

- `PetDrawing.cs`: 내장 스프라이트 시트를 4칸으로 읽고, 실행 중에만 150ms마다 프레임을 바꿉니다.
  얼굴·책상·모니터는 같은 기준 프레임을 유지하며 앞발 영역만 합성하여 배경 흔들림을 줄입니다.
- `Assets/cat-typing.png`: 승인한 고양이를 참조해 imagegen으로 생성한 2×2 타이핑 프레임입니다.
- 기존 `Assets/cat-desk.png`는 원본으로 보관합니다. 표시에는 타이핑 시트의 정지/동작 프레임을 사용합니다.
- `--animation-preview`를 실행하면 실제 앱 렌더러가 `app/typing-preview.gif`를 만듭니다.
- 생성 프롬프트 요약: 동일한 3D 고양이·책상·의자 구도를 유지하고,
  가까운 앞발 들기 → 양발 내리기 → 먼 앞발 들기 → 양발 내리기의 4프레임을 투명 배경에 배치.
